# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the iplist project.

## List of ADRs

| ADR | Title | Status |
|-----|-------|--------|
| 0001 | Cross-platform whois and ipcalc replacement | Accepted |
| 0001 (packaging) | macOS port and standalone binary packaging | Accepted |
| 0002 | WorkerException preload for clean PHAR shutdown | Accepted |

Note: Two ADRs share number 0001 covering different concerns — command-level portability (whois/ipcalc) vs binary packaging (macOS port). ADR 0002 covers WorkerException preload for PHAR shutdown.
