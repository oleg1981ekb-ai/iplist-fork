# Quickstart (macOS)

Быстрый старт iplist на macOS — автономный бинарник, без PHP/Docker.

## Требования
- macOS (Intel x86_64 или Apple Silicon M1–M4 через Rosetta 2).
- Сеть: доступ в интернет для загрузки списков с GitHub и DNS‑запросов.
- Порт: свободный локальный порт 8080.

## Шаг 1. Установка
```bash
curl -fsSL https://github.com/oleg1981ekb-ai/iplist-fork/releases/download/v1.0.0-macos/install.sh | bash
```

Скрипт скачает статический PHP‑бинарник (micro build) и PHAR‑пакет, разместит их в `~/.local/share/iplist/runtime/`, создаст обёртку `~/.local/bin/iplist`.

> Если `iplist` не найден — выполните `source ~/.zshrc` или откройте новое окно терминала.

## Шаг 2. Запуск
```bash
iplist
```

Сервер начнёт загрузку списков и DNS‑резолвинг.

> [!TIP]
> Первый запуск занимает 5–15 минут: преобразуются более 33 000 доменов в IP‑адреса и подсети CIDR. Веб‑интерфейс доступ сразу после начала слушания.

## Шаг 3. Первый список
1. Откройте в браузере [http://127.0.0.1:8080](http://127.0.0.1:8080).
2. Выберите категорию (например, `ai`) или конкретные сервисы.
3. Укажите формат (например, `Text`, `JSON`, `MikroTik`) и тип данных.
4. Используйте полученную ссылку в роутере.

## Остановка
Ctrl+C в терминале запуска.

Перед публикацией: точную PHP‑версию лучше фиксировать в release notes; для Quickstart используйте нейтральную формулировку «автономный статический бинарник PHP 8.x (spc micro build)».
